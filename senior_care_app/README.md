# Senior Citizen Daily Care

## Project Description
Senior Citizen Daily Care is a web application designed to help senior
citizens maintain their daily routines. It helps guardians manage
activities, track water intake, and monitor task completion.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local development server: XAMPP

## Main Features
- User registration and login
- Guardian and senior citizen roles
- Care Circle for managing senior profiles
- Daily timetable and repeat-day scheduling
- Activity status tracking (Done and Skip)
- Daily water intake tracking
- Weekly task completion chart
- PHP session-based authentication

## Database
Database name: senior_care

Tables:
- users
- people
- tasks
- task_days
- task_logs
- water_logs

## Running the Project
1. Start Apache and MySQL in XAMPP.
2. Ensure the senior_care database exists.
3. Place the project in C:\xampp\htdocs\senior_care_app.
4. Open http://localhost/senior_care_app/ in your browser.
5. Register an account or sign in with an existing account.

## Important
Keep a database backup before deleting test records or changing
the database structure. Use test accounts for demonstrations.
